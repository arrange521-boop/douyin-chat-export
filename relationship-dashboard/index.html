高信息证据库

默认收录：长间隔主动重启、边界表达、共同事务执行、照顾提醒、能耗≥4 的句子。

四层 Hybrid Cognitive Pipeline

1. 元数据层：响应延迟、消息长度、长间隔重启、对话轮次、时间分布。

2. 语义与心理层：只做场景行为和功能判断；不硬贴“大五人格/回避型”等永久标签。

3. 时序动态层：观察“接近 → 边界 → 降频 → 恢复”“冲突后是否撤退”“线下亲密后次日是否降温”等序列。

4. 现实锚点层：旅行、见面、身体接触、成本、第三方事件等单独补录，用来纠正“文字热络但现实疏离”。

核心证据权重

高：重复 + 主动 + 跨场景 + 有成本 + 后续不撤退。
中：单次主动、明确事务执行、个性化照顾。
低：回复速度、表情、单句暧昧、一次“不躲”。

反幻觉规则

不把“不回复”解释成试探，不把“边界”解释成反话，不用“她就是因为喜欢才防御”这种不可证伪逻辑。每条推断都必须允许反证。
